# 内容标准

## 三类核心卡

**世界故事**：寓言、民间故事、神话传说、经典文学的小片段。明确原典/版本与讲述方式；可做原创转述，但不整段照抄受保护译文。神话和传说不可用确定史实的口吻讲。

**人物故事**：选择一个人的一次行动、选择、爱好或人生片段，而不是罗列完整年表。真实人物不能凭空获得对话、动机或心理独白。材料不足时标注不确定性，或换题。

**历史名城**：以城门、街道、河流、建筑或某个历史转折为入口，讲城市的一个面向。不为了“氛围”捏造当晚天气、钟声或具体街景；想象段必须与资料段分开。

原创内容仍允许，但不是卡池的唯一来源。

## 阅读体验

独立完整，语气面向成人且适合睡前；不考试、不强行升华、不制造追更焦虑。可保留真实历史的复杂性，不因“温柔”抹去事实；主动避开以血腥、恐怖或强烈虐心为卖点的选题。

## 来源与素材

史实优先采用博物馆、档案馆、官方遗产机构、原始文献及可靠研究。争议性说法需要交叉核对；单个机构页面可支持有限、明确、非争议的样例事实，但不能由此声称全面核验。

每张卡至少记录来源标题、机构/作者、URL、访问日期、支持的具体信息、复用方式。搜索结果可发现素材，不自动授予图片或长文的发布权利。

图片需记录作者、出处、许可/授权状态、替代文本和“实拍 / 艺术作品 / 生成插画”性质。未核对权利的素材不打包发布；样卡当前不包含图片。具体发布范围和许可问题在上线前逐条核查，不把本文件当成法律意见。

## 数据层

`category` 表示故事/人物/城市；`content_nature` 表示内容性质；`format` 表示实际展示形式。三者不能混用。`review_status` 只表示事实审核进度，不能代替授权记录；`release_status` 表示是否正式发布。

`reflection` 是编辑收束，必须明确为编辑文字，不应伪装成史料原句。`editorial_note` 记录改编、删节与不确定性。`related_tags` 允许松散关联，不制造虚构的历史联系。

## 生产前检查

来源对应正文；题名不过度煽情；没有虚构历史对话；传说明确标识；图片实际可访问且可用；阅读长度合适；同一个故事不能换标题就算新题；旧题重访明确标“重访”。
