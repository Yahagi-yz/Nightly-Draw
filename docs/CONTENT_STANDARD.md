# 内容标准

## 三类核心卡

**世界故事**：寓言、民间故事、神话传说、经典文学故事。明确原典/版本与讲述方式；单次须独立完整，不能用截断的片段或编辑读后感补成故事。可做原创转述，但不整段照抄受保护译文。神话和传说不可用确定史实的口吻讲。

**人物卡**：以介绍人物、让读者读完确实认识这个人为目标，采用有故事感的人物小传。篇幅可以稍长；交代身份与时代、成长背景、关键经历及选择、代表贡献、生活或性格的不同侧面，以及人生结局或当前阶段。轶事可以辅助呈现人物，不能用一则孤立轶事代替人物介绍，也不要求逐年罗列全部履历。真实人物不能凭空获得对话、动机或心理独白。材料不足时标注不确定性，或换题。

**历史名城**：以城门、街道、河流、建筑或某个历史转折为入口，讲城市的一个面向。不为了“氛围”捏造当晚天气、钟声或具体街景；想象段必须与资料段分开。

原创内容仍允许，但不是卡池的唯一来源。

## 人物卡的参考写法

用户已确认：人物卡就是介绍人物，允许较长篇幅，最好参考网上已有的经典格式；不是“人物的一件小事 + 编辑赏析”。以下参考的是文章的组织方式，不是照搬文字，也不是宣称存在唯一的通用模板。

- V&A《Introducing Beatrix Potter》：先定位人物，再串联成长环境、兴趣、创作、重要关系与晚年生活。借鉴其将多个身份组织成一段人生的方式。
  - https://www.vam.ac.uk/articles/introducing-beatrix-potter
- 《宋史》卷338《苏轼传》：从人物出身进入生平，通过具体作为和关键处境展现人物。借鉴以事见人的传记叙述，不照搬古文、长篇奏疏、官职清单或史家的褒贬判断。
  - https://zh.wikisource.org/wiki/宋史/卷338
- 维基百科《Su Shi》：人物定位、早年、仕途、家庭与作品的分层可用作信息覆盖检查。百科结构不是最终阅读语气；具体史实仍尽量回到原典或可靠研究。
  - https://en.wikipedia.org/wiki/Su_Shi

上述页面于本次2026-09-09会话中读取。V&A只作为写法范例，不是其他人物的事实来源。

候选骨架：人物名与一句身份定位 → 成长与时代背景 → 关键经历及选择 → 作品、贡献与生活侧面 → 晚年/当前阶段及留下的影响 → 来源与必要说明。

这是编辑骨架，不要求每张卡机械使用同样的小标题，也不强迫所有人生套入成功、逆袭或励志结构。可以先写一个有依据的代表场景，但应尽快转入人物整体。家庭、性格与作品可嵌入人生主线，不必另开百科式栏目。

建议初版正文约1200—2000个中文字，随人物复杂度和阅读反馈调整。这是可逆的编辑建议，不是用户批准的硬字数阈值；没有实测时不把阅读分钟数当作事实。

人物卡正文不使用“我读到这里”“我最喜欢的一句”等阅读过程叙述；不混入古文赏析、对读者说教、强行鸡汤或“今晚你可以学到什么”。可以解释事件之间的关系和作品的意义，但应基于证据，不冒充人物内心。

人物小传的验收：读者能知道此人是谁、处于什么时代、经历过哪些关键转折、做过什么重要的事、有哪些不能被单一标签概括的侧面，以及其人生结局或当前阶段。删去轶事和编辑感想后，如果人物仍然几乎空白，则不通过。

此前3张短样卡和预览仍只是结构演示；本次文档修订不表示既有数据、模板渲染或推送指令已经全部改造，也不表示定时任务已启用。

## 阅读体验

独立完整，语气面向成人且适合睡前；不考试、不强行升华、不制造追更焦虑。可保留真实历史的复杂性，不因“温柔”抹去事实；主动避开以血腥、恐怖或强烈虐心为卖点的选题。

## 来源与素材

史实优先采用博物馆、档案馆、官方遗产机构、原始文献及可靠研究。争议性说法需要交叉核对；单个机构页面可支持有限、明确、非争议的样例事实，但不能由此声称全面核验。原始文献的作者立场也须考虑，亲友墓志或后代史书的评价不能无条件当作客观事实。

每张卡至少记录来源标题、机构/作者、URL、访问日期、支持的具体信息、复用方式。搜索结果可发现素材，不自动授予图片或长文的发布权利。

出处与必要的编辑说明在阅读界面放到正文后的来源区；保留事实到来源的对应关系，不在故事中穿插检索过程或阅读感想。对话交付使用可追溯的引用。

图片需记录作者、出处、许可/授权状态、替代文本和“实拍 / 艺术作品 / 生成插画”性质。未核对权利的素材不打包发布；样卡当前不包含图片。具体发布范围和许可问题在上线前逐条核查，不把本文件当成法律意见。

## 数据层

`category` 表示故事/人物/城市；`content_nature` 表示内容性质；`format` 表示实际展示形式。三者不能混用。`review_status` 只表示事实审核进度，不能代替授权记录；`release_status` 表示是否正式发布。

`reflection` 是既有数据中的编辑收束字段，必须明确为编辑文字，不应伪装成史料原句。不得为了填充这个字段而给人物卡强加读后感或启示；后续改造数据与渲染时应允许不展示此类内容，并另行验证兼容性。本次只修改编辑规范，没有修改数据契约。

`editorial_note` 记录改编、删节与不确定性。`related_tags` 允许松散关联，不制造虚构的历史联系。

## 生产前检查

来源对应正文；题名不过度煽情；没有虚构历史对话；传说明确标识；图片实际可访问且可用；阅读长度合适；同一个故事不能换标题就算新题；旧题重访明确标“重访”；人物卡通过上述人物小传验收。
