# 验收清单

## 内容与数据

- 三种题材均有样例，样例正文与来源一致。
- 传说、寓言、史实和改编明确区分；编辑收束不伪装为引语。
- 数据 ID 唯一，来源完整，图片型卡存在实际图片字段且权利记录不为待定。
- 时区固定 Asia/Shanghai，期望时间为22:00；没有以设备时区覆盖。
- 样卡标记 sample_only，而不是生产发布。

## GitHub

- 新仓库实际存在于正确账号，默认分支与文件可读。
- 项目文件上传成功，不借用或覆盖其他仓库。
- 沿用用户创建仓库时的公开性；不提交私人数据、密钥，也不擅自改变可见性。
- 已存在的本项目不再执行建仓脚本；保留脚本的默认无副作用预演检查。

## 推送

- 真实任务已创建，不以配置文件代替任务。
- 触发时交付完整内容，不是只催用户来抽。
- 图片不可用时能降级；同一天重复运行不重复发。
- 无外部数据访问时不捏造来源。
- 设备通知权限、一次实际发送以及首个定时触发有验证记录。

## App（后续）

- 本地预览不能作为上线证明。
- 平台、技术栈、账户和运行成本经确认后再实施。
